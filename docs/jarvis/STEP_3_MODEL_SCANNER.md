# Jarvis — Step 3: local model inventory and scanner

Status: service, pure classifier, SAF import bridge and Local Model Library screen committed on `feature/jarvis-step-2-storage-privacy`.

## Architecture decisions

- Reuse OGAM's existing `modelManager` registry and reconciliation instead of creating a competing model database.
- Refresh the existing text GGUF and image-model registries through `modelManager.refreshModelLists()`.
- Include Whisper files from the existing `whisperModelFiles.listDownloadedModels()` catalogue.
- Read installed GGUF headers with `readModelHeader()`, which calls `llama.rn.loadLlamaModelInfo()` without loading the model.
- Estimate installed text-model RAM with `estimateTextModelMemoryMB()`, the same estimator used by the actual load gate. Do not substitute a simple file-size multiplier.
- For external folders, use the existing SAF `nativeDirectorySourceBoundary.enumerate()` bridge. Enumeration returns metadata only and does not copy large model weights.
- Add `documentUri()` to the existing native SAF bridge so the selected file can be copied directly once into the model-owned destination by the established importer.
- Import single-file GGUF, LiteRT and Whisper files through the existing storage/validation paths. GGUF imports attach a strictly matching mmproj when present.
- Multi-part GGUF files are not offered as importable yet because the existing local importer does not admit all split parts atomically. They remain visible in the scan.
- The screen does not request broad storage access; Android's folder picker is used. The screen reports that direct SAF folder scanning is Android-only.

## Recognized external artifacts

- GGUF primary files and companion mmproj files.
- LiteRT `.litertlm` models.
- Whisper `ggml-*.bin`.
- MNN `.mnn` weights.
- QNN model `.bin` candidates and QNN runtime `libQnn*.so` libraries.
- `manifest.json`.
- LoRA and other `.safetensors` files.

Classification is not proof that a pack is runnable. MNN/QNN/LoRA artifacts remain non-importable until a later validation step checks required companion files, manifest schema, backend/device compatibility and licensing. A QNN runtime library found in a user folder is not automatically copied into the APK.

## RAM and GGUF metadata

- The local inventory reports GGUF architecture and `general.file_type` when the header is readable.
- Estimated RAM is generated by the production model-loading estimator, including the current app's inference settings and model metadata.
- SAF-only files are not parsed or loaded during enumeration. They are inspected only after explicit import into app-owned storage, avoiding a staging copy of a potentially multi-gigabyte file.
